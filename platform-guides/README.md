# 將設定帶到不同 AI

設定精靈最後生成的 `我的AI工作夥伴設定.md` 是可攜式內容，但不同 AI 的保存位置不同。

## 共通原則

1. 先完成真實工作測試，再保存設定。
2. 公司共通規則與個人偏好分開保存。
3. 單次客戶、訂單、帳務或人事資料不要寫進永久設定。
4. 平台沒有永久指令功能時，在新對話開始時重新貼入設定。
5. 設定有修改時，保留日期或版本，避免使用過期內容。
