# AI 協作學習紀錄

本紀錄分成兩部分：第 1 部分是跨部門固定欄位，供課程負責人彙整比對；第 2 部分是同仁自述，用於課堂驗收。未知的欄位一律填「未提供」，不編造。

## 第 1 部分｜跨部門固定欄位

| 欄位 | 填寫方式 | 本次內容 |
|---|---|---|
| record_id | 日期與流水號；未知不編造 | |
| learner_id | 同仁自行設定代號；未知填未提供 | |
| department | 所屬部門 | |
| task_type | 沿用部門優先工作，或註記新情境 | |
| used_at | 使用日期；未知填未提供 | |
| platform | 使用的 AI 平台；未知填未提供 | |
| case_type | 真實去識別化／虛構練習 | |
| task_goal | 本次要完成什麼 | |
| initial_issue | 第一版哪裡不好用；未觀察到問題就照實記錄 | |
| user_revision | 實際補資料、追問或修改的動作；未修正則註記 | |
| final_status | 草稿／待核／可用；「可用」需註明同仁判斷或主管確認 | |
| evidence | 去識別化前後差異短摘錄或成果位置；無資料填未提供 | |
| skill_evidence | 講清需求／辨認錯誤／補資料修正／核對資料／採用條件，各標示已觀察或未觀察 | |
| next_practice | 依本次紀錄提出一項練習建議 | |
| reviewer_status | 未驗收／主管確認／需重做；未收到主管回覆一律為未驗收 | |
| knowledge_used | 本次是否引用既有部門知識；有則填 knowledge_id，未使用填「未使用」 | |
| knowledge_candidate | 本次有無可重複使用的做法；未經主管確認只能標「待確認」 | |
| linked_knowledge_id | 經主管確認並寫入部門知識後才填；否則填「未建立」 | |
