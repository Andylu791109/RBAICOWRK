# 業務夥伴資料夾設定

第一次使用時，在自己的電腦或公司核准的雲端硬碟建立以下資料夾：

```text
森呼吸_直播設計/
├── 00_品牌共用/
│   ├── Logo/
│   ├── 字體與色彩/
│   └── 已核准範例/
├── 01_直播專案/
│   └── YYYY-MM-DD_直播主題/
│       ├── 01_需求與文案/
│       ├── 02_原始素材/
│       ├── 03_AI工作版本/
│       ├── 04_核准成品/
│       └── 05_設計回報/
└── 99_封存/
```

## 第一次建立

1. 建立最上層資料夾 `森呼吸_直播設計`。
2. 建立 `00_品牌共用`、`01_直播專案`、`99_封存`。
3. 每次直播在 `01_直播專案` 新增一個資料夾，名稱使用 `YYYY-MM-DD_直播主題`。
4. 在直播專案內建立五個子資料夾，依用途放置檔案。
5. 只有主管已核准且可重複使用的資料，才放入 `00_品牌共用`。

## 檔案放哪裡

| 內容 | 資料夾 |
|---|---|
| 直播需求、日期、價格、必放文字 | `01_需求與文案` |
| 商品照、人物照、背景圖 | `02_原始素材` |
| AI 產生的初稿與修改版 | `03_AI工作版本` |
| 主管確認採用的最終圖片 | `04_核准成品` |
| AI 產出的《直播設計回報》 | `05_設計回報` |

## 檔名規則

使用：

```text
YYYYMMDD_直播主題_平台_比例_版本
```

例如：

```text
20260920_秋季新品_IGStory_9x16_v01.png
20260920_秋季新品_FBPost_1x1_FINAL.png
20260920_秋季新品_直播設計回報.md
```

只有主管核准的版本使用 `FINAL`。修改中的版本使用 `v01`、`v02`、`v03`。

## 與 ChatGPT 雲端 Project 的分工

- 資料夾：保存原始檔、工作版本、核准成品及回報檔。
- ChatGPT Project：保存對話、上傳素材、專案指令與本次 AI 工作脈絡。
- GitHub：保存主管確認過的設計規則、學習紀錄及可公開的正反例。

ChatGPT 雲端 Project 不會自動同步電腦資料夾。開始每場直播設計時，請將本次需要的素材上傳到對應對話；完成後再把下載的成品與回報放回正確資料夾。

## 封存

直播結束且主管確認資料完整後，將整個直播專案移到 `99_封存`。不要刪除原始素材、核准成品和設計回報，除非公司資料保存規則另有要求。
