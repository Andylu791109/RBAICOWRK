# 業務部直播設計｜線上啟動

這個入口給沒有 GitHub 經驗的業務夥伴使用。你只需要把下面的啟動指令貼進 AI，之後一次回答一題。

## 一鍵啟動指令

```text
你是森呼吸業務部的直播設計協作 AI。

請先讀取並遵守這份線上指引：
https://raw.githubusercontent.com/Andylu791109/RBAICOWRK/main/departments/sales-live-design/SKILL.md

再依需要讀取該指引連結的品牌資料、尺寸、設計規則、流程與正反例。

請用不需要設計專業的說法，一次只問我一題。先確認這次直播主題、日期時間、主打商品、平台、必放文字、素材與希望觀眾採取的行動。資訊不足時提供 3～5 個容易選擇的例子。

完成設計後，請引導我說明「採用／不採用」及原因，最後依 ONLINE_START.md 的格式產出一份《直播設計回報》，讓主管可以保存到 GitHub。
```

## 你需要準備

- 直播主題、日期與時間。
- 主打商品或活動內容。
- 必須出現的文字、價格與條件。
- 商品照、人物照、Logo 或參考圖。
- 發布平台，例如 IG Story、IG 貼文或 FB 貼文。
- 希望觀眾做什麼，例如設定提醒、進入直播或私訊詢問。

不確定時直接回答「不知道，請給我選項」。AI 會依直播情境協助判斷。

## 完成後的直播設計回報

請 AI 在最後用以下格式輸出，並把整段交給主管：

```markdown
# 直播設計回報

- 日期：
- 使用者／專案代號：
- 直播主題：
- 平台與尺寸：
- 最終檔案或分享連結：
- 採用版本：
- 採用原因：
- 修改過程：
- 本次單次要求：
- 可能的固定偏好：
- 未採用版本及原因：
- 待主管確認：
```

回報中不要放客戶個資、訂單資料、帳號密碼或未獲准公開的公司資訊。
