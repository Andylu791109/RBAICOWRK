# 業務部直播設計｜線上啟動

這個入口給沒有 GitHub 經驗的業務夥伴使用。整個對話可以放在 ChatGPT 雲端專案中，不必下載 GitHub 或在電腦執行程式。

## 第一次使用：建立雲端專案

1. 登入 ChatGPT，建立一個 Project，命名為「森呼吸｜業務部直播設計」。
2. 在 Project 中建立新對話，命名為 `YYYY-MM-DD｜直播主題`，例如 `2026-09-20｜秋季新品直播`。
3. 把下方「一鍵啟動指令」貼進這個對話。
4. 將本次要使用的商品圖、人物照、Logo 和參考圖上傳到同一個對話。
5. 每場直播建立一個新對話；共用的品牌資料與已核准範例放在 Project 來源中。

ChatGPT 雲端 Project 可將相關聊天、上傳檔案與指令集中管理；網頁版的雲端工作也能在關閉桌面應用後繼續。不過雲端 Project 無法直接讀取你電腦裡的資料夾，因此需要主動上傳本次素材。

第一次使用時，再依 [`FOLDER_SETUP.md`](FOLDER_SETUP.md) 建立自己的直播設計資料夾。這個資料夾保存原始素材與核准成品；ChatGPT Project 保存對話和雲端工作脈絡。

## 一鍵啟動指令

```text
你是森呼吸業務部的直播設計協作 AI。

請先讀取並遵守這份線上指引：
https://raw.githubusercontent.com/Andylu791109/RBAICOWRK/main/departments/sales-live-design/SKILL.md

再依需要讀取該指引連結的品牌資料、尺寸、設計規則、流程與正反例。

請用不需要設計專業的說法，一次只問我一題。先確認這次直播主題、日期時間、主打商品、平台、必放文字、素材與希望觀眾採取的行動。資訊不足時提供 3～5 個容易選擇的例子。

完成設計後，請引導我說明「採用／不採用」及原因，最後依 ONLINE_START.md 的格式產出一份《直播設計回報》，讓主管可以保存到 GitHub。
```

## 你需要準備

- 直播主題、日期與時間。
- 主打商品或活動內容。
- 必須出現的文字、價格與條件。
- 商品照、人物照、Logo 或參考圖。
- 發布平台，例如 IG Story、IG 貼文或 FB 貼文。
- 希望觀眾做什麼，例如設定提醒、進入直播或私訊詢問。

不確定時直接回答「不知道，請給我選項」。AI 會依直播情境協助判斷。

## 完成後的直播設計回報

請 AI 在最後用以下格式輸出，並把整段交給主管：

```markdown
# 直播設計回報

- 日期：
- 使用者／專案代號：
- 直播主題：
- 平台與尺寸：
- 最終檔案或分享連結：
- 採用版本：
- 採用原因：
- 修改過程：
- 本次單次要求：
- 可能的固定偏好：
- 未採用版本及原因：
- 待主管確認：
```

回報中不要放客戶個資、訂單資料、帳號密碼或未獲准公開的公司資訊。

## 讓主管看得到

完成後請把以下三項交給主管：

1. 最終採用圖片或雲端檔案連結。
2. AI 產出的《直播設計回報》。
3. 若帳號提供對話分享功能，可一併提供只讀分享連結；分享前先確認對話中沒有敏感資料。

雲端對話不會自動寫回 GitHub。主管確認回報後，再將學習內容保存到 `DESIGN_LOG.md`、`DESIGN_MEMORY.md` 與正反例資料夾。
