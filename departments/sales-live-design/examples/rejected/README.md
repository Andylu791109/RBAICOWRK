# Rejected｜未採用案例

這裡保存有學習價值的退回版本與具體原因，用來避免重複犯錯。拒絕一個版本不等於永久禁止其所有元素。

## 新增方式

1. 圖片命名為 `R001_專案_平台_日期.png`；若有對應修正版，在說明中連到 Approved 編號。
2. 寫出可觀察的問題與修正方向，避免只寫「不好看」。
3. 圖片需先確認可公開並完成去識別化；不適合上傳時只保留文字紀錄。
