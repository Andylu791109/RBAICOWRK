# 社群文案風格

所有欄位先以真實採用案例校準。沒有證據時，以清楚、精簡、可行動為預設，並避免自行創造優惠、期限或承諾。

## 品牌語氣

- 稱呼受眾方式：待確認
- 語氣關鍵字：待確認
- 常用詞：待確認
- 避免用詞：待確認
- 中英文與標點習慣：待確認
- Emoji 使用：待確認

## 圖上文字原則

- 一張圖只承擔一個主要訊息。
- 主標能在手機縮圖中快速讀懂。
- 內文保留必要資訊；完整說明可放貼文文字。
- CTA 使用明確動詞，說清楚下一步。
- 日期、時間、價格、折扣、門檻與連結視為高風險資訊，逐字核對來源。

## 常用結構

### 活動／直播

主標 → 核心亮點 → 日期時間 → CTA

### 商品促銷

商品或利益點 → 必要條件 → 價格／期限 → CTA

### 品牌公告

公告主題 → 對受眾的影響 → 生效時間 → 下一步或聯絡方式
