# 部門 AI 工作助手指令

這裡是各部門「可以直接複製貼上給 AI」的引導指令，依該部門主管訪談的卡點、交付格式與核對邊界調整過。

## 怎麼用

這些檔案是**給 AI 讀取執行**的，同仁不需要自己打開來看。

到 [`../../WORKER_START_PROMPT.md`](../../WORKER_START_PROMPT.md) 複製自己部門那一整段（含連結），貼進正在使用的 AI 送出，AI 讀完就會直接開始問第一題。

沒有材料時，AI 會使用清楚標示的「虛構示例」，不會假裝是真實公司資料。

## 狀態說明

- 指令中的「主管已確認背景」來自該部門主管訪談，屬公司事實。
- 指令的流程設計、工作選項與檢查安排屬 **AI 建議，尚未經主管核定**，供課堂試用。
- 標為「待確認」的項目由同仁帶回主管補充，AI 與同仁都不得自行補成公司規則。
- 每份指令的工作選項都只是預設。同仁今天做的不是那幾項時可選「E｜今天不是這幾項」，AI 會改照他實際的工作協助。
- 人資與總務行政的訪談沒有問到主管驗收標準，該部門的驗收欄維持待確認。
