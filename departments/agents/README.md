# 部門 AI 工作助手指令

這裡是各部門「可以直接複製貼上給 AI」的引導指令，依該部門主管訪談的卡點、交付格式與核對邊界調整過。

## 怎麼用

1. 找到自己的部門檔案。
2. 複製「可直接複製的指令」整段，貼進你正在使用的 AI。
3. 依 AI 的提問一次回答一題，並貼上一項手邊已有的材料。
4. 第一版產出後，對照 [`../../templates/DELIVERY_CHECK.md`](../../templates/DELIVERY_CHECK.md) 自檢再送出。

沒有材料時，使用清楚標示的「虛構示例」，不得假裝是真實公司資料。

## 狀態說明

- 指令中的「主管已確認背景」來自該部門主管訪談，屬公司事實。
- 指令的流程設計、練習情境與檢查安排屬 **AI 建議，尚未經主管核定**，供課堂試用。
- 標為「待確認」的項目由同仁帶回主管補充，AI 與同仁都不得自行補成公司規則。
