# 各部門工作情境索引

這些內容提供給 AI 作為「選項生成參考」，不是固定答案，也不是公司正式制度。

當使用者說「不知道」或無法想到工作案例時，AI 應依其部門提供 4～6 個具體、容易辨認的情境，每次只問一題。

- [`LIVE_COMMERCE.md`](LIVE_COMMERCE.md)：直播
- [`SALES.md`](SALES.md)：業務
- [`PRODUCT.md`](PRODUCT.md)：產品
- [`CUSTOMER_SERVICE.md`](CUSTOMER_SERVICE.md)：客服
- [`HR_ADMIN.md`](HR_ADMIN.md)：人資與總務行政
- [`SHIPPING_WAREHOUSE.md`](SHIPPING_WAREHOUSE.md)：出貨與倉庫
- [`PROCUREMENT.md`](PROCUREMENT.md)：採購
- [`FINANCE.md`](FINANCE.md)：財務
- [`MANAGEMENT.md`](MANAGEMENT.md)：主管與跨部門
- [`SPA.md`](SPA.md)：SPA 課程、服務與活動

## 已校準的公司情境

[`CALIBRATED_CONTEXT.md`](CALIBRATED_CONTEXT.md) 保存主管已確認的工作、驗收邊界、AI 課堂試用建議與待確認事項。AI 在同仁選定部門後，應優先讀取對應章節；通用部門文件作為沒有校準資料時的備援。

除 `CALIBRATED_CONTEXT.md` 明確標為「主管已確認」的內容外，部門文件中的例子都是通用或虛構情境。AI 不得據此推測公司現行規則。

出貨、倉庫、採購與直播的選項應以基層執行人員也能直接看懂的方式呈現，必要時在每個選項後加入括號範例。
