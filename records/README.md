# 去識別化學習紀錄

這裡保存已完成公開前檢查的單次工作紀錄。每筆紀錄沿用 [`AI 協作學習紀錄範本`](../templates/AI_LEARNING_REPORT_TEMPLATE.md)，路徑為 `records/<department>/<record_id>.md`。`record_id` 使用日期與流水號，例如 `20260923-001`；`department` 使用小寫英文部門名稱，例如 `sales`、`product`、`customer_service`、`procurement`、`shipping_warehouse`。未來新增部門時，在這份索引補上對應名稱。

同一位夥伴的每筆紀錄使用相同的隨機 `learner_id`，讓主管能從案例證據比較成長。**代號不得包含姓名、工號或部門縮寫；代號與真人的對照表不得提交本 Repo。**若部門和工作情境仍可能辨識個人，應改寫或不公開該筆紀錄。

提交前依 [`GitHub 紀錄流程`](../facilitator/GITHUB_RECORD_LOOP.md) 完成主管檢查與去識別化。這個資料夾只收案例，不收原始對話、個人績效評語或公司未公開資料。尚無實際紀錄時維持空目錄，不用虛構案例填充。
