# 部門知識

這裡只放**經主管確認、可在相近工作重複使用**的規則、判斷依據與正反例。單次嘗試與未核實的 AI 推論留在 [`records/`](../records/README.md)，不能直接寫成公司做法。

新增知識時複製 [`部門知識條目範本`](../templates/DEPARTMENT_KNOWLEDGE_ENTRY_TEMPLATE.md)，存為 `knowledge/<department>/<knowledge_id>.md`。每條知識要能回查去識別化的來源紀錄、適用範圍、主管確認狀態，以及後續有沒有被再使用。公開前再次依 [`隱私規則`](../PRIVACY_AND_SUBMISSION.md) 檢查。某項做法被新案例推翻時，更新原條目並保留修正原因。
