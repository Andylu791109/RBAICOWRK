# 主管部門 AI 需求訪談｜一鍵啟動 Prompt

## 給課程負責人

只要把下方整段文字傳給主管。主管直接貼進 ChatGPT、Gemini、Claude 或其他可讀取網址的 AI，不需要下載、建立或上傳任何啟動 MD。

```text
請完整讀取以下 GitHub Raw 文件，並依照文件內的「AI 執行規則」進行主管訪談：

https://raw.githubusercontent.com/Andylu791109/RBAICOWRK/main/facilitator/SUPERVISOR_CALIBRATION_WIZARD.md

執行要求：
1. 不要摘要文件，也不要先列出全部問題。
2. 讀取成功後，直接開始第 1/10 題。
3. 一次只問一題，最多讓我作答 10 次。
4. 問題必須依照我提供的部門與實際工作調整，不可只用職稱套入一般題庫。
5. 回答不清楚時記為待確認並繼續，不可增加題數或無限追問。
6. 第 10 題結束後，依文件規定建立一個新的訪談結果 .md 檔案，供我下載並回傳課程負責人。
7. 不要要求我下載或建立訪談啟動檔，也不要把回答寫回 GitHub。

如果你無法讀取連結，請直接明說無法讀取，不可假裝已讀。讀取成功後現在直接開始訪談。
```

## 使用結果

訪談完成後，主管只需將 AI 產出的「部門名稱_AI工作引導設計資料_日期.md」私下傳給課程負責人。
