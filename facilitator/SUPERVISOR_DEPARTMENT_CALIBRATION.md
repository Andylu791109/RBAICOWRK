# 主管部門 AI 盤點｜十題備援表

優先使用 [啟動 Prompt](SUPERVISOR_START_PROMPT.md)，由 AI 提供符合部門的白話選項。本表不是額外作業；不使用互動版才填，每題一句即可，不確定填待確認。

| 題次 | 框架 | 問題 | 回答 |
|---|---|---|---|
| 1 | 部門 | 這次先整理哪個部門？ | |
| 2 | 優先工作 | 最希望 AI 先幫同仁做好哪件事？ | |
| 3 | 目前卡點 | 這件事最常讓你提醒或重做的是什麼？ | |
| 4 | 完成樣子 | 同仁做到什麼樣子，你會覺得有幫助？ | |
| 5 | 已有資料 | 同仁手上通常已有什麼？ | |
| 6 | 先確認事項 | 哪些內容不能自己答應？ | |
| 7 | 目前程度 | 目前多數同仁使用 AI 的狀況？ | |
| 8 | 課後進步 | 一段時間後最希望看到什麼改變？ | |
| 9 | 回報方式 | 每週一筆代表案例／每次完成就記／課後兩週整理／其他／待確認？ | |
| 10 | 最後補充 | 有沒有沒問到或需要更正的地方？沒有可略過。 | |

完成後連同 [精靈全文](SUPERVISOR_CALIBRATION_WIZARD.md) 交給 AI，輸入：「十題已填，請直接生成部門引導與學習追蹤 MD，不重問、不另做確認；缺漏列待確認。」

AI 依統一框架轉成主管需求卡、同仁引導指令、檢查點與課後使用紀錄欄位。這次收集的是主管期望；實際學習成效需要後續案例與驗收證據。

MD 私下回傳課程負責人，不提交主管回答或敏感資訊到公開 Repo。
