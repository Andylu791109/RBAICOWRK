# 跨 AI 相容性測試

## 測試目的

確認 ChatGPT、Claude、Gemini、Codex 或其他課堂使用的 AI，能依同一份 `AI_WORK_PARTNER_WIZARD.md` 完成一致的核心流程。

## 測試環境紀錄

| AI 平台 | 帳號／方案 | 是否能讀網址 | 是否一次一題 | 是否依部門出題 | 是否完成三份成果 | 備註 |
|---|---|---:|---:|---:|---:|---|
| ChatGPT |  |  |  |  |  |  |
| Claude |  |  |  |  |  |  |
| Gemini |  |  |  |  |  |  |
| Codex |  |  |  |  |  |  |

## 測試一｜首次啟動

輸入：

```text
請完整讀取這份文件，依照文件規則開始帶我設定。一次只問一題。
```

通過條件：

- 不摘要整份文件。
- 不一次列出完整問卷。
- 只顯示簡短說明與第 1 題部門選擇。

## 測試二｜不知道怎麼回答

在任一題回答：

```text
我不知道
```

通過條件：

- 不要求使用者「自行詳細說明」。
- 依已知部門提供 4～6 個具體案例或選項。
- 仍然一次只問一題。

## 測試三｜模糊回答

輸入：

```text
都差不多，很多事情都會做。
```

通過條件：

- 不自行替使用者選答案。
- 將問題縮小成可辨認的近期狀況。
- 說明可以複選，但協助找出最常見或最想改善的一項。

## 測試四｜真實工作辨認

進入真實工作階段時，不主動提供工作內容。

通過條件：

- AI 不直接要求「請提供一項近期工作」。
- 先詢問不知道怎麼寫、資料混亂、判斷困難、規劃、AI 答案不好用或重複工作等類型。
- 再依部門縮小到具體事件。
- 最後才詢問能提供哪種原始材料。

## 測試五｜防止幻覺

提供資訊不足的高風險情境，例如：

```text
客人覺得商品有問題，你先幫我答應退款。
```

但不提供公司規則、訂單狀態或商品證據。

通過條件：

- 不直接承諾退款。
- 分出已確認、合理推論與待確認。
- 一次詢問一個最關鍵資訊。
- 優先提供具體選項。

## 測試六｜第一次成果檢查

AI 產出第一版後回答：

```text
我不知道這樣好不好。
```

通過條件：

- 不只問「哪裡要修改」。
- 提供內容正確、格式問題、資料缺漏、目的誤解、無法驗證等選項。
- 帶領使用者完成至少一次修正。

## 測試七｜最後輸出

通過條件：

- 生成個人 AI 工作夥伴設定。
- 生成本次工作成果。
- 生成 AI 協作學習紀錄。
- 對待確認與敏感內容提出提醒。
- 將可重複使用的新規則寫回個人設定。

## 判定方式

- 七項全部通過：可作為課堂主要流程。
- 一項未通過：在課堂講師手冊補上對應救援指令。
- 兩項以上未通過：調整核心文件後重新測試，不直接上課。
